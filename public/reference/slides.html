01 The Shift

The unit changed — and
now it's pooled.

  • On June 1, 2026 Premium Request Units retired. Everything meters in GitHub AI Credits (1 credit = $0.01).
  • Billed on input + output + cached tokens at each model's published API rate.
  • Enterprise seats are $39/user — base prices unchanged.
  • The enterprise twist: credits are pooled at the billing entity. No per-seat bucket — one shared reservoir.
  • The old safety net is gone: an exhausted budget is a hard wall, not a quiet downgrade to a cheaper model.
Your job as a team isn't to police individuals — it's to govern a shared resource with policy, budgets, and good defaults.

02 Shared Pool, Shared Responsibility

One runaway loop
drains everyone.

The risk

A single developer's vague mega-task in agent mode can burn thousands of credits from the pool the whole team shares.

The reframe

Cost discipline isn't a personal virtue here — it's collegial. Efficient habits leave runway for teammates.

The fix

Good defaults + guardrails make the cheap path the easy path, so nobody has to think about it.

Everything that follows splits into two tracks: developer habits that scale across the team, and admin controls that bound the worst case.

04 Models · The Standard

Set the default once, for everyone

Auto as the org default

Routes by availability & complexity, hugs cache boundaries, and gives paid seats a 10% multiplier discount. GA in all three environments.

Lightweight for routine

nano / mini / Flash for boilerplate, quick edits, and planning. Publish this as the team convention.

Frontier by exception

Opus · GPT-5.5 · Fable 5 reserved for documented hard cases — gate behind policy where the spend warrants it.

Runway, made concrete: 1,500 credits buys ~500K GPT-5.5 output tokens — or ~12M nano tokens. Multiply that 24× gap across every seat. (Hopping models mid-session re-breaks the cache.)
05 Context Engineering · As a Team Standard

Every token is billed
every turn

Start fresh

New task → new chat (⌘N / CLI /clear). Long threads reprocess all of themselves each reply.

Scope, don't dump

Attach with #file #sym @ instead of letting the agent inhale the repo.

Compact & fork

/compact to summarize long sessions; /fork to branch without re-establishing context.

Trim the toolbelt

Every tool & MCP definition costs context each turn. Disable what the task doesn't use.

Plan, then build

Reason once to a plan, review it, hand off to a cheaper model for the mechanical edits.

Ride the cache

Cached input is ~10× cheaper. Short, focused sessions on a stable prompt hit cache best.

06 Shared Context at Org Scale

Encode standards in version control

Always-on

A lean repo copilot-instructions.md — it's billed every turn, so keep it tight.

Scoped

*.instructions.md + applyTo globs load only for matching files. Cheaper than one giant file.

Memory

Repo facts & user preferences (Business/Enterprise) reused across agents; unused entries expire in 28 days. Curate.

Protect it

Guard governance files with CODEOWNERS + branch protection so standards can't be quietly edited.

Net effect across the team: fewer re-explanations, better first-try output — which means fewer billed round-trips per developer, multiplied by every seat.
07 Exclusions · An Enterprise Power

Keep files out — cheaper and safer

Server-side · Enterprise

Content exclusion

Org / repo / enterprise policy via fnmatch patterns. Excluded files get no suggestions, no chat context, skipped in review. Propagation up to 30 min; JetBrains needs a restart.

Client-side

.copilotignore

VS Code & CLI, .gitignore-style. Trims build output, generated files, unrelated monorepo packages. Commit a shared one — but it's not a security guarantee.

Enterprise gets a real enforced policy (content exclusion) on top of developer-side hygiene. Use both: policy for secrets, .copilotignore for token discipline everywhere.
07 The Gap

Exclusions don't reach the agent

  • Content exclusion is not supported in Copilot CLI, the cloud agent, or Agent mode in IDE chat.
  • Agentic workflows spin up isolated environments that don't inherit path-exclusion filters.
  • A cloud agent checking out a branch can read files under an excluded path. Documented limitation, not a bug.

Layered defense (org policy)

Don't rely on one wall:

  • Content exclusion + shared .copilotignore
  • AGENTS.md rules: never read *.env *.pem *.key
  • PreToolUse hooks, default-deny
  • Keep secrets out of the repo — secret managers, not files
If a developer can read a file, the agent probably can too. Bake "no secrets in the working tree" into onboarding.

09 Budget Architecture

Four nested guardrails

Enterprise budget — outer cap on metered overage. Max bill = licenses + this budget.
Cost-center budgets — per-team caps & chargeback.
User-level budgets (ULB) — per-seat hard stop, checked first, always enforced.
Shared credit pool — included allowance
The universal ULB (a default applied to every user) is your most important single control — set it above the per-seat value, then override upward for verified power users.
09 The Rules That Actually Stop Spend

Alerts aren't limits

Enable the hard stop

On enterprise & cost-center budgets, switch on "Stop usage when budget limit is reached." Otherwise it's alert-only.

Set the alerts

Thresholds at 75 / 90 / 100% for early warning — to admins and owners, not just after the wall.

Mind the overage gate

The "AI credit paid usage" policy must be on to allow any overage; off → usage blocks the moment the pool empties.

There is no automatic fallback to a cheaper model when a budget runs dry. ULBs always hard-stop — a $0 ULB blocks a user immediately, even with pool left.
10 Monitoring & Chargeback

Make the pool legible

Admin

Org dashboards

Billing → AI usage: filter by user, model, organization, or cost center; export CSV for chargeback and trend analysis. Reset date + alerts at 75/90/100%.

Developer

In-flow visibility

VS Code status-bar % of allowance · Agent Debug Logs & Cache Explorer · CLI /usage per session.

Operate on signals: users blocked before mid-cycle → ULB too tight or a power user needs an override. Metered charges while the pool isn't empty → ULBs collectively exceed the pool; raise the enterprise budget or tighten ULBs.
11 Across the Toolchain

Same standard, three surfaces

VS Code

Richest controls: /compact · /fork · Cache Explorer · selective context loading. The reference implementation for your standards.

JetBrains IDEA

Watch the project-root trap: instruction files scope to the IDE project root, not the Git repo root. Content exclusion needs an IDE reload; no native /compact.

Copilot CLI

/usage · /clear · launch inside the package. The .github/ bulk-load can add 150k+ tokens — keep it lean.

Govern the gap: content exclusion does not apply to the CLI, cloud agent, or agent mode on any surface. Same standards, same blind spot — cover it with AGENTS.md + hooks + secret hygiene.

13 The Enterprise Cheat Sheet

Two tracks, one pool

Admins & leads
  • Universal ULB + hard stop; overrides from data
  • Enterprise & cost-center budgets with "stop at limit"
  • Content exclusion + model-availability policy
  • Baseline in the promo; review usage monthly
Developers
  • Auto or lightweight; frontier on purpose
  • Fresh chats, tight context, #/@ refs
  • Chat over Agent unless a loop is truly needed
  • Lean on free completions for routine flow
